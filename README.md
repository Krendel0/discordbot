# Discord Economy Bot

Простой бот для Discord с экономикой, вдохновленной UnbelievaBoat. Поддерживает наличные и банковский баланс, ежедневные бонусы, работу, переводы между пользователями и таблицу лидеров.

## Возможности
- Команды `!balance` / `!bal` для просмотра баланса (наличные, банк, общее).
- `!daily` — ежедневная награда с 24-часовым откатом.
- `!work` — случайная зарплата раз в час.
- `!deposit` / `!withdraw` с поддержкой аргумента `all`.
- `!pay @user amount` — перевод наличных другим участникам.
- `!leaderboard` — топ по общему капиталу.
- Данные хранятся в SQLite (`data/economy.db`).

## Требования
- Python 3.10+.
- Токен Discord-бота (переменная окружения `DISCORD_TOKEN`).

## Установка и запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# создайте файл .env на основе примера и пропишите токен бота
cp .env.example .env
echo 'DISCORD_TOKEN="ваш_токен_бота"' >> .env

python bot.py
```

**Не публикуйте файл `.env` и не делитесь токеном бота.** Токен в примере предназначен только для локального использования
и не должен попадать в репозиторий.

Бот использует префикс `!`. Для корректной работы команд по содержимому сообщений включите интент Message Content в панели разработчика Discord и убедитесь, что у бота есть права на чтение/отправку сообщений.

## Структура
- `bot.py` — точка входа, команды Discord.
- `economy.py` — слой работы с базой данных SQLite и бизнес-логика экономики.
- `data/` — каталог для файла базы данных (создается автоматически).

## Развитие
Вы можете расширить бота, добавив магазины, роли за валюту или дополнительные способы заработка. Команды построены на `discord.ext.commands`, поэтому легко добавлять новые коги.
